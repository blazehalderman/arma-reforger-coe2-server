# PRMaxxpro

> **One-line role**: M1224 Maxxpro MRAP content pack (US Army heavy MRAP) from the PR mod family.

## 1. Overview

Adds the Navistar M1224 MaxxPro MRAP — a V-hulled mine-resistant ambush-protected vehicle widely used by US Army in OEF/OIF — as a GM-spawnable BLUFOR armored transport. Part of the "PR" (Project Reality) mod family which uses the shared `PR_UTILS` framework.

## 2. Functionality / Features

- M1224 MaxxPro MRAP prefab(s); typical variants ship with M2 .50 cal or M240 cupola
- V-hull mine resistance, ~6-passenger capacity
- US Army skins
