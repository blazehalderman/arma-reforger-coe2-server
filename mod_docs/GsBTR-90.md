# GsBTR-90

> **One-line role**: BTR-90 8x8 wheeled IFV content pack (modern Russian).

## 1. Overview

Adds the BTR-90 (Rostok) modern 8x8 wheeled IFV with 30mm autocannon + ATGM — fills the modern Russian wheeled IFV gap between BTR-80 (vanilla) and BMP/BMD tracked IFVs.

## 2. Functionality / Features

- BTR-90 prefab with 30mm 2A42 cannon + 7.62mm PKT coax + AT-5 Spandrel ATGMs
- Crewed turret (commander + gunner) + driver + troop bay
- Russian / OPFOR skins
