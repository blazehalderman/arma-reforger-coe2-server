# ZSU-23-4

> **One-line role**: ZSU-23-4 "Shilka" tracked self-propelled anti-aircraft gun (Soviet/OPFOR SPAAG).

## 1. Overview

Adds the ZSU-23-4 "Shilka" — the Soviet quad-23mm radar-directed tracked SPAAG — as a GM-spawnable OPFOR anti-air / anti-light-armor / anti-infantry asset. Equally deadly to helicopters and exposed infantry.
