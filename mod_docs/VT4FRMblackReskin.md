# VT4FRMblackReskin

> **One-line role**: Black + green-digital-camo reskin of the VT4 Chinese MBT (FRM VT4 base required).

## 1. Overview

Cosmetic reskin pack giving the VT4 (Chinese export MBT, MBT-3000/VT-4) a black and green digital-camo paint scheme. Reskin built on top of the upstream "FRM VT4" base mod (`663B2784961621FB`) — "FRM" appears to be the community/author name of that base mod (not explicitly defined on the Workshop page; author credits "the FRM community for there mod and works"). Faction usage flexible (Chinese export customers use a VT4 — Thailand, Pakistan, Nigeria — or as a generic OPFOR/PMC asset).

## 2. Functionality / Features

- Black + green digital-camo VT4 variant
- No new turret/armament — pure texture replacement on the FRM VT4 base prefab
- Spawns alongside vanilla FRM VT4 in GM entity browser
