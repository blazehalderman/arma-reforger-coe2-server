# RealismOverhaulLighting

> **One-line role**: rebalances ambient + directional lighting + flashlight / vehicle-headlight beams for realism.

## 1. Overview

Lighting half of the RealismOverhaul suite. Brightens daylight contrast curves, deepens shadow falloff, tightens flashlight / weapon-light beams, retunes vehicle headlight cones.

## 2. Functionality / Features

- Daylight HDR curves retuned.
- Flashlight + weapon-light cone tightening + reach extension.
- Vehicle headlight beam reshape.
- Indoor / underground darker by default.
