# GMTrenches

> **One-line role**: adds placeable trench / earthwork / sandbag prefabs to the Game Master entity browser.

## 1. Overview

Small GM-content mod — bolts a category of placeable fortifications (slit trenches, fighting positions, sandbag walls, foxholes) onto the GM entity picker. Useful for sculpting defensive positions ahead of an AI assault.

## 2. Functionality / Features

- Trench / earthwork prefab pack.
- Sandbag and HESCO wall variants.
- Placed via standard GM workflow.

## 3. Configuration

_No config file._

## 4. Operator usage

GM mode → entity browser → look for the "Trenches" / "Fortifications" sub-category.

## 5. Compatibility & load order
