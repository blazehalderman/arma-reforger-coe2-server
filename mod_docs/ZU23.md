# ZU23

> **One-line role**: ZU-23-2 towed dual-23mm anti-aircraft autocannon (Soviet/insurgent light AA).

## 1. Overview

Adds the ZU-23-2 — the classic towed dual-barrel 23mm anti-aircraft autocannon, ubiquitous across Soviet/Warsaw Pact, insurgent (technicals), and ex-Soviet states — as a GM-spawnable emplaced or towed AA gun. Lighter / dismountable counterpart to the tracked ZSU-23-4 Shilka.

## 2. Functionality / Features

- ZU-23-2 emplacement prefab with twin 23mm 2A14 autocannons
- 1-2 crew (gunner + loader)
- Anti-air, anti-light-armor, anti-infantry — deadly to helis and soft-skinned vehicles
- Typically used emplaced; some variants pintled to technicals (Toyota Hilux pickup mounts)
