# Wirecutters2

> **One-line role**: adds a usable wirecutter item that opens passages through fences and barbed wire.

## 1. Overview

Functional tool mod — gives players a wirecutter inventory item that opens player-traversable holes in chain-link and barbed-wire fences. Useful for COE2-style infiltration objectives.

## 2. Functionality / Features

- Wirecutter inventory prefab.
- Player action to cut a fence section.
- Persistent passage (cut sections stay cut until scenario reload).

## 3. Configuration

_No config file._

## 4. Operator usage

Players need a wirecutter in inventory; aim at a fence section, hold the use action.
