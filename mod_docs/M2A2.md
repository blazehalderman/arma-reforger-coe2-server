# M2A2

> **One-line role**: M2A2 Bradley IFV content pack (US Army tracked IFV).

## 1. Overview

Adds the M2A2 Bradley Fighting Vehicle — the US Army's standard tracked IFV — with 25mm M242 Bushmaster + TOW ATGMs. Base content pack for `HorsemansBlackBradley` reskin.

## 2. Functionality / Features

- M2A2 Bradley prefab with 25mm M242 Bushmaster autocannon + 7.62mm M240C coax + TOW ATGM launcher
- Crewed turret (commander + gunner) + driver + ~6 dismount seats
- US Army skins; WCS_Armaments dep wires up real-attachment system for the autocannon
