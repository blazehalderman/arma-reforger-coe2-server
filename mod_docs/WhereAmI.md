# WhereAmI

> **One-line role**: HUD overlay showing the player's current grid coordinates + named-location/region in screen corner.

## 1. Overview

Lightweight HUD helper — shows current 8/10-figure grid + nearest named-place tag in a screen corner so players don't have to open the map to know where they are. Standard QoL on milsim-style servers.

## 2. Functionality / Features

- Grid coordinate HUD.
- Nearest-place name lookup.
- Toggleable via keybind.
